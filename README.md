# 论文翻译目录

本仓库通过 GitHub Pages 发布逐段中英对照的论文译稿。网站首页是 `index.html`，每篇译稿保留独立的 HTML 文件。

## 添加下一篇译稿

1. 将完整 HTML 放入 `papers/` 目录，文件名使用论文英文题目关键词和修订日期，例如 `example-paper-bilingual-zh-2026-10-16.html`。
2. 在 `index.html` 的“已收录论文”区域复制一张论文卡片，更新标题、日期及相对链接，例如 `./papers/example-paper-bilingual-zh-2026-10-16.html`。
3. 提交并推送到 `main` 分支；GitHub Pages 会从仓库根目录重新发布。

第一篇译稿的带日期文件仍保留在仓库根目录，以维持已经分享的直达链接。更新译稿时请避免覆盖或改名已发布文件；如需保留不同修订版，可新增日期文件并更新目录链接。

此仓库为**公开仓库**：提交到这里的文件及提交历史对所有人可见，上传前请检查内容。
